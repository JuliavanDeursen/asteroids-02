ASTEROIDS
This game is a 2D game in which the player is a spaceship. You move by pressing the arrow buttons. You are able to rotate pressing right and left, and accelerate by pressing the up arrow. You can shoot bullets by pressing the spacebar. During the game different kinds of asteroids try to hit you. WHen they hit you the game is over. You can eliminate these asteroids by shooting at them and thereby also earn points. As the game progresses the asteroids will increasingly get more difficult to destroy. During the game you can pause and resume by pressing p. Once the game finishes you will see your final score and a list of top 10 highest scores. You can play again by pressing R. 

How to Run the Game
1. Clone or download the project.
2. Open a terminal in the project directory.
3. Run the following command: cabal run

The game window will open automatically.
